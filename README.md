## APIs
- **beehiiv Publications API** — Read publication metadata and configuration.
- **beehiiv Subscriptions API** — Create, list and manage subscribers.
- **beehiiv Posts API** — Create, update and retrieve newsletter posts.
- **beehiiv Automations API** — Manage and enroll subscribers in automations.
- **beehiiv Custom Fields API** — Manage custom subscriber data attributes.
- **beehiiv Segments API** — Create and manage subscriber segments.
- **beehiiv Tiers API** — Manage paid subscription tiers.
- **beehiiv Polls API** — Manage polls and read responses.
- **beehiiv Webhooks API** — Subscribe to real-time platform events.
- **beehiiv OAuth2 API** — OAuth2 authorization and token management for partner integrations.
